Comment créer un QR code gratuit

Un lien, un texte, ton invitation Discord : voici comment fabriquer un QR code propre et facile à scanner, sans compte.

À quoi sert un QR code ?

Un QR code est un carré de petits points que l'appareil photo d'un téléphone lit en une seconde. Il contient un texte, le plus souvent l'adresse d'un site. Il évite à ton public de taper un lien à la main : on le met sur une affiche, une carte de visite, un flyer, un menu, une vitrine, ou sur un écran pendant une présentation.

Créer ton QR code en 4 étapes

  1. Ouvre le générateur et colle ton lien ou ton texte dans la case. Le QR code apparaît tout de suite, sans bouton à presser.
  2. Choisis la taille : petit, moyen ou grand. Prends « grand » si tu comptes l'imprimer.
  3. Règle la qualité de lecture (normale, bonne, haute ou maximale). Plus elle est haute, mieux le code résiste à un petit défaut ou à une tache, mais plus il contient de points.
  4. Choisis si tu veux les couleurs par défaut ou les tiennes, puis télécharge l'image au format PNG.

Nos conseils pour qu'il se scanne bien

  • Garde un fort contraste. Un code foncé sur un fond clair est le plus fiable. L'outil t'avertit si le contraste est trop faible ou si ton code est plus clair que son fond.
  • Ne le fais pas trop petit à l'impression. Compte au moins 2 cm de côté pour un lien court, et plus si le texte est long.
  • Raccourcis ton lien. Moins il y a de caractères, moins il y a de points : le code est plus simple et plus facile à lire.
  • Laisse une marge blanche autour. L'outil l'ajoute pour toi : ne la rogne pas.
  • Teste avant d'imprimer. Scanne-le avec deux téléphones différents.

Questions fréquentes

Un QR code expire-t-il ?
Non. Le code contient directement ton texte ou ton lien : il fonctionne tant que la page vers laquelle il pointe existe.

Ce que j'écris est-il envoyé quelque part ?
Non. Le QR code est fabriqué dans ton navigateur, sur ton appareil, et ton texte n'est ni envoyé ni enregistré.

Quelle est la différence entre les niveaux de qualité ?
Ils correspondent à la part du code qui peut être abîmée sans empêcher la lecture : environ 7 % pour « normale », 15 % pour « bonne », 25 % pour « haute » et 30 % pour « maximale ». Pour un écran, « bonne » suffit. Pour un support imprimé exposé à l'usure, prends « haute ».

Puis-je mettre des accents ou des émojis ?
Oui, le texte est encodé en UTF-8, donc les accents et les émojis sont acceptés.
